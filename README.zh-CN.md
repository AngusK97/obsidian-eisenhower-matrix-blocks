# Eisenhower Matrix Blocks：Obsidian 四象限任务插件

[![CI](https://github.com/AngusK97/obsidian-eisenhower-matrix-blocks/actions/workflows/ci.yml/badge.svg)](https://github.com/AngusK97/obsidian-eisenhower-matrix-blocks/actions/workflows/ci.yml)
[![GitHub release](https://img.shields.io/github/v/release/AngusK97/obsidian-eisenhower-matrix-blocks?sort=semver)](https://github.com/AngusK97/obsidian-eisenhower-matrix-blocks/releases)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/AngusK97/obsidian-eisenhower-matrix-blocks/blob/main/LICENSE)

**把四象限任务管理直接放进 Obsidian 笔记。**

按重要性与紧急程度安排工作，不必离开当前笔记。为任务添加截止日期、可选时间、彩色标签和备注，拖拽排序，保留可筛选的完成记录。每张矩阵都属于所在笔记，不依赖另一套任务数据库。

**Obsidian 1.5.0+ · 桌面与手机 · 中文与 English · 本地优先**

- **矩阵之间互不影响：** 任务和完成记录只属于所在矩阵；同一篇笔记也可以插入多张矩阵。
- **数据保存在 Markdown 中：** 象限、任务顺序和完成时间都会随笔记一起同步和备份。
- **操作集中在矩阵内：** 添加、编辑、移动、完成、恢复、删除和筛选任务都不需要离开当前笔记。
- **任务清楚分组：** 独立轻背景卡片、紧凑的信息行，以及添加区与滚动列表之间的固定分隔线。
- **空间灵活可控：** 象限自动适应可用宽度，整张矩阵可折叠，完成记录可限高滚动。

矩阵会插入当前光标位置，成为笔记内容的一部分。

## 快速开始

1. [安装插件](#安装方式)，然后在 Obsidian 中启用 **Eisenhower Matrix Blocks**。
2. 打开一篇可编辑的 Markdown 笔记，将光标放在需要插入矩阵的位置。
3. 点击左侧功能区中的网格图标，或在命令面板中运行 **Eisenhower Matrix Blocks：在当前光标处插入四象限**。
4. 切换到实时预览或阅读视图，即可使用渲染后的矩阵。

每次执行插入命令都会新建一张独立矩阵。需要在同一篇笔记中加入第二张矩阵时，再执行一次命令即可。

默认四个象限分别用于：**立即做**（重要且紧急）、**安排**（重要不紧急）、**委派**（紧急不重要）、**舍弃**（不重要不紧急）。它们是整理任务的分类；移动到“委派”不会自动把任务发送给其他人。

## 安装方式

### 通过社区插件市场安装

1. 打开 Obsidian 的 **设置 → 第三方插件**。
2. 点击 **浏览**，搜索 **Eisenhower Matrix Blocks**。
3. 点击 **安装**，然后启用插件。

### 手动安装

1. 打开[最新版本页面](https://github.com/AngusK97/obsidian-eisenhower-matrix-blocks/releases/latest)，下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在 Obsidian 库中创建 `.obsidian/plugins/eisenhower-matrix-blocks/` 文件夹。
3. 将下载的三个文件放入该文件夹。
4. 重新加载 Obsidian，然后在第三方插件列表中启用 **Eisenhower Matrix Blocks**。

### 更新插件

在 **设置 → 第三方插件** 中检查更新，并在每台设备上更新本插件。手动更新时，使用**同一个 Release** 中的三个文件覆盖安装目录，然后重新加载插件或 Obsidian；不要删除笔记或 `data.json`。GitHub 自动提供的 **Source code** 压缩包不是可直接安装的插件包。

升级前请备份笔记。**所有设备须先更新到 2.7.0 或更高版本，再编辑标签或截止时间**：旧版本保存矩阵时可能丢弃这些字段。当前说明与预览图均对应 [2.8.1](https://github.com/AngusK97/obsidian-eisenhower-matrix-blocks/releases/tag/2.8.1)，版本变化见[更新日志](CHANGELOG.md)。

## 每张矩阵都属于所在笔记

每张矩阵只管理自己的任务和完成记录：

- 每篇项目笔记都可以拥有自己的矩阵和完成记录。
- 同一篇笔记可以放置多张互不影响的矩阵。
- 将矩阵代码块复制到另一篇笔记，会连同数据一起复制。在**同一篇笔记**中应通过插入命令新建矩阵：直接复制会造成矩阵 ID 重复，插件将拒绝写入以保护数据。
- 删除代码块会删除对应矩阵，请保留笔记历史或备份。
- 操作矩阵时，只会更新当前代码块；正文、属性、Callout 块、其他代码和同文件中的其他矩阵都会原样保留。
- 插件完全在本地运行，不发送网络请求，也不收集遥测数据。

## 可以做什么

| 操作 | 说明 |
|---|---|
| 添加 | 输入任务名称，可选填截止日期、时间、标签和备注；只填名称也可添加，新任务出现在象限顶部。 |
| 编辑 | 单击进行中或已完成任务，即可编辑所有字段；名称中回车保存，备注中 Ctrl/Cmd+Enter 保存，标签中回车添加标签。 |
| 移动与排序 | 可拖动任务切换象限或调整同象限顺序；触摸屏和触控笔使用拖拽手柄，所有设备仍可使用任务菜单。 |
| 完成 | 勾选任务后，它会移入统一的已完成列表，并记录具体完成时间。 |
| 恢复 | 取消勾选已完成任务后，任务会回到原象限的底部。 |
| 筛选 | 已完成默认显示今天，可切换全部、近 7 天、近 30 天或自定义时间段，并按来源象限筛选。 |
| 管理空间 | 可把整张矩阵折叠为数量摘要；已完成默认限高滚动，可一键切回完整高度。 |
| 改名 | 每张矩阵都可以单独设置标题；默认标题为 `Matrix`。 |
| 自定义象限 | 每个象限都可以单独修改标题和副标题，也可以恢复为跟随界面语言的默认文案。 |

## 任务详情

| 字段 | 是否必填 | 展示与编辑方式 |
|---|---|---|
| 名称 | 是 | 自然换行；点击任务即可编辑。 |
| 截止日期 | 否 | 完整的 `YYYY-MM-DD`、英文星期缩写及相对天数。 |
| 截止时间 | 否 | 可选填 `00:00`–`23:59`；需先设置日期，未设置时不显示。 |
| 标签 | 否 | 不限数量的固定配色标签；过长标签在卡片中截断。 |
| 备注 | 否 | 弹窗多行编辑，卡片单行预览；省略显示不会删除原文。 |

### 截止日期与紧急程度

截止日期按设备本地日历计算。卡片显示完整日期与星期缩写（Mon–Sun）、可选的 24 小时时间、剩余/逾期天数和备注预览，各单元完整换行。日期、星期、时间与相对天数使用同一紧急程度颜色。

支持的平台使用浏览器/系统原生日历，不支持弹出选择器时仍可直接操作原生日期输入框，具体外观随平台变化。清除日期会一并清除时间；也可以只清除时间。

时间清除按钮收在时间控件的统一边框内：空值时完全隐藏、不占位置，有值或尚未输入完整时才显示。清除只影响时间，日期保留，焦点回到时间框。添加区和编辑弹窗共用该控件，手机清除按钮点击面积仍为 44px。

| 截止状态 | 显示方式 |
|---|---|
| 未完成：逾期、今天或未来 3 天内 | 红色，显示闹钟图标 |
| 未完成：未来 4–7 天 | 黄色 |
| 未完成：超过 7 天 | 绿色 |
| 已完成：不论截止日期 | 截止日期、星期、可选时间弱化显示，不显示倒计时或紧急闹钟 |

已完成任务保留原截止信息和完成时间，但不再显示“已逾期”“还剩 X 天”或“今天到期”。恢复到象限后，相对天数与紧急程度颜色会重新显示。此调整只影响显示，不修改已存储日期。

任务截止信息显示日历或紧急闹钟图标与“**截止**”；实际完成时间在来源象限旁单独显示，使用圆圈勾图标与“**完成于**”。常用操作采用统一图标、可访问名称和悬停说明，筛选仍保留文字。已完成区的展开按钮只改变列表高度，不改变日期筛选。日期输入只保留一个原生日期框及平台日历入口，去掉旁边重复的日历按钮。

闹钟只是**视觉状态提示，不是通知或提醒功能**。天数与颜色按本地自然日计算，不按剩余小时计算。可选时间按输入值显示，不会在不同时区之间自动换算。

### 标签与键盘操作

标签数量不限，回车、逗号或换行确认标签，保存时也包含末尾尚未确认的一项；点击 × 可逐项移除。同名标签由固定哈希映射到跨设备一致的颜色，深浅主题均使用可读配色。标签仅属于任务，不写入 Obsidian 全局标签索引。

标签区分大小写（`Work` 与 `work` 不同），规范化后完全相同的标签会去重；不同标签可能使用同一种颜色。支持英文和中文逗号，目前不提供标签筛选或全局标签管理。

| 光标所在位置 | 按键 | 效果 |
|---|---|---|
| 添加区或编辑弹窗的名称 | Enter | 添加或保存任务 |
| 备注 | Enter | 换行 |
| 备注 | Ctrl/Cmd + Enter | 添加或保存任务 |
| 标签 | Enter | 添加标签，不提交整条任务 |

输入法组词期间不会提前提交任务，确认中文候选词与提交任务分开处理。

## 布局与完成记录

- 在矩阵折叠按钮旁选择 **自动布局 / 田字型 / 纵向排列**。每个矩阵会在当前设备记住选择，重新打开笔记或重启 Obsidian 后仍然恢复，不修改笔记栏宽或其他矩阵。
- **自动布局**保留现有响应式规则：矩阵内部可用宽度 **≤620px**，或应用视口宽度 **≤720px** 时采用单列，否则两列。**纵向排列**始终单列。
- **田字型**固定两列，每列至少 300px 以保持任务可读；空间不足时只在矩阵内部左右滑动，整篇笔记和已完成区不跟着横滚。聚焦象限区域可用方向键滚动，拖动任务到边缘也会自动横滚到另一列。窄列保留完整标题、日期、星期和可选时间，长标签/备注省略后可点任务查看；手柄仍可打开操作菜单，不再占用重复的更多按钮位置。
- 每个象限的添加区及分隔线位于独立滚动列表之外。触摸端从手柄开始拖动，轻点手柄打开操作菜单；桌面悬停或键盘聚焦任务时显示操作按钮。
- 已完成默认筛选**今天**并**限高滚动**。筛选依据是**完成日期**，不是截止日期；选择“全部”查看更早记录，使用展开/滚动按钮切换完整高度与滚动显示。
- 折叠整张矩阵后，摘要显示矩阵名称、各象限名称与数量，以及已完成数量。

布局按 Vault、笔记和矩阵分别保存在本机，电脑与手机独立记忆；选择“自动布局”清除覆盖值。同一矩阵的多个窗口同步选择，在 Obsidian 内重命名/移动笔记或文件夹也会保留。清空应用本地存储，或在应用关闭期间从外部改动笔记路径，可能重置偏好。布局不写入 Markdown 或插件 `data.json`，切换时保留输入，包括尚未确认的标签。更新至 2.8.2 或更新版本后，重新选择一次所需布局即可保存。

折叠、筛选、滚动显示模式和未提交输入仍属于临时视图状态，重新打开或重建视图可能恢复默认；离开笔记前请先保存草稿。

## 同步与数据安全

一张矩阵的全部数据都保存在它的 Markdown 代码块中。

- 使用 Obsidian Sync、Remotely Save 或 Git 同步笔记时，矩阵会像其他 Markdown 内容一样随笔记同步。
- 如果多台设备同时离线修改同一篇笔记，冲突仍由所使用的同步工具处理。
- 删除矩阵代码块就等于删除这张矩阵，因此建议保留笔记历史或定期备份。

界面语言与矩阵数据分开保存。切换语言不会改写笔记内容；是否需要在每台设备上重新设置，取决于同步工具的配置。

## 手机端与语言设置

在 Obsidian Mobile 中，四个象限会根据屏幕宽度自动改为单列布局。从任务拖拽手柄开始移动时，靠近象限列表或笔记边缘会自动滚动；不使用拖拽手势时，仍可通过任务菜单切换象限、上移或下移。

打开 **设置 → Eisenhower Matrix Blocks → 界面语言**，可选择默认的 **跟随 Obsidian**、**中文** 或 **English**。文案、菜单、相对天数、完成时间格式及提示会更新，不会改写矩阵代码块。两种语言下的截止日期均保持 `YYYY-MM-DD`，星期保持 `Mon`–`Sun`。

单击象限标题区域的铅笔按钮，可以同时修改该象限的标题和副标题。自定义文案属于笔记内容，切换界面语言时不会自动翻译；选择“恢复默认”后，该象限会重新跟随界面语言。

## 常见问题

### 同一篇笔记可以放多张矩阵吗？

可以。每次需要新矩阵时，再运行一次插入命令即可。

### 任务会在不同设备间同步吗？

会。矩阵数据保存在笔记中，因此会随笔记一起同步。界面语言等插件设置单独保存在 `.obsidian` 目录中，是否同步取决于同步工具的配置。

### 可以直接编辑 Markdown 源码吗？

可以阅读和手动修改，但更建议使用插入命令和矩阵界面，由插件自动维护任务信息。如果代码块内容不完整或格式错误，需要先修复源码才能继续操作。

### 没有网络也能使用吗？

可以。插件完全在本地运行，本身不需要联网。

### 为什么电脑上也显示纵向布局？

即使窗口最大化，笔记区域仍可能小于布局断点，详见[布局与完成记录](#布局与完成记录)。使用插件不要求修改整个笔记库的正文宽度。

### 为什么之前完成的任务看不到了？

完成记录默认只显示今天。切换到“全部”，并检查来源象限筛选；筛选不会删除任务。

### 为什么看到的是代码块，而不是矩阵？

先确认插件已启用，并使用实时预览或阅读视图；源码模式本来就显示 Markdown。若提示 ID 重复或数据格式错误，请先备份并修复代码块；同一笔记新增矩阵应使用插入命令。

### 会自动收集整个笔记库的待办或发送提醒吗？

不会。插件只管理自己的矩阵代码块，不汇总全库任务、不发送后台通知，也不提供日历服务集成。
